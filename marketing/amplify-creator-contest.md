## What GameArena is (for someone new)

A web game arena you play on any phone, no download. Skill games plus an AI agent,
MARKOV, you can play against. Every game is a transaction on Celo, so the
leaderboard is on-chain, not something we type in. The catch that makes it
different: you can't enter without passing GoodDollar face verification. One
human, one account, no bots.

## Set this before launch (so the leaderboard scores THIS contest, not all-time)

On Railway, set the contest window so /creator-contest counts only referrals
brought during it:

  CREATOR_CONTEST_START=2026-09-27T18:00:00Z    # today, 6pm WAT = 17:00 UTC — adjust
  CREATOR_CONTEST_END=2026-10-04T18:00:00Z      # +7 days

Without these it defaults to all-time. The page also accepts ?since= / ?until=
ISO if you want to check a window without changing env.
